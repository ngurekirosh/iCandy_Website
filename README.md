### Step 3: Download the File

Locate the correct file for your operating system. Click the download link for that file. Your browser will start downloading it. 

### Step 4: Install the Application

- **For Windows:**
  1. Once the download is complete, navigate to your Downloads folder.
  2. Double-click the `.exe` file.
  3. Follow the installation prompts.

- **For macOS:**
  1. Open your Downloads folder.
  2. Double-click the `.dmg` file.
  3. Drag the iCandy app into your Applications folder.

- **For Linux:**
  1. Open your terminal.
  2. Navigate to the folder where you saved the downloaded file.
  3. Use the command: `chmod +x iCandy_Website` to make the file executable.
  4. Run the application using `./iCandy_Website`.

### Step 5: Open the Application

After installation, locate the iCandy app on your computer. Open it, and you will see an intuitive interface that is easy to navigate.
